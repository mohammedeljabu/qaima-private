# دليل رفع Qaima على Render - خطوة بخطوة

## الملفات الجاهزة:
- server.js (محدث لـ Render - يقرأ PORT من البيئة)
- package.json
- data.json (المطاعم)
- orders.json (الطلبات)
- public/index.html (لوحة التحكم)

## الخطوات:

### الخطوة 1: إنشاء حساب GitHub (إذا لم يكن لديك)
1. ادخل github.com
2. سجل حساب جديد

### الخطوة 2: إنشاء Repository جديد
1. في GitHub اضغط New repository
2. اسمه: qaima-private
3. اختر Public
4. اضغط Create

### الخطوة 3: رفع ملفات المشروع
- حمل هذا المجلد كامل على جهازك
- افتح Terminal داخل المجلد
- شغل:
  git init
  git add .
  git commit -m "Qaima private project - manual subscriptions"
  git branch -M main
  git remote add origin https://github.com/USERNAME/qaima-private.git
  git push -u origin main

(استبدل USERNAME باسمك في GitHub)

### الخطوة 4: إنشاء حساب Render
1. ادخل render.com
2. سجل باستخدام GitHub (Sign up with GitHub)
3. سيطلب صلاحية - وافق

### الخطوة 5: إنشاء Web Service
1. في لوحة Render اضغط New + > Web Service
2. اختر Repository qaima-private
3. الإعدادات:
   - Name: qaima-private
   - Region: Frankfurt (أقرب لأوروبا وليبيا)
   - Branch: main
   - Runtime: Node
   - Build Command: npm install
   - Start Command: npm start
   - Plan: Free

4. اضغط Create Web Service

### الخطوة 6: انتظر 2-3 دقائق
- Render سيبني المشروع وينشره
- ستحصل على رابط مثل: https://qaima-private.onrender.com

### الخطوة 7: افتح رابطك!
- افتح الرابط - ستجد لوحة التحكم الخاصة بك تعمل
- البيانات محفوظة في ملفات data.json و orders.json على السيرفر

### ملاحظات مهمة:
- الخطة المجانية في Render تنام بعد 15 دقيقة بدون استخدام - أول زيارة بعد النوم تأخذ 30 ثانية لتصحو
- إذا أردت سيرفر لا ينام، اختر Starter Plan 7$ شهريا
- البيانات في الخطة المجانية قد تمسح عند إعادة النشر - احتفظ بنسخة من data.json
- لا يوجد دفع تلقائي - أنت تتحكم يدويا كما طلبت

### كيف تحدث المشروع بعد الرفع؟
- عدل الملفات في جهازك
- ثم: git add . && git commit -m "update" && git push
- Render سيعيد النشر تلقائيا
