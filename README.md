# Qaima - مشروعك الخاص لإدارة اشتراكات المطاعم
## نسخة سيرفر خاص - بدون دفع تلقائي

### هذا مشروعك الخاص 100% - أنت تتحكم بكل شيء يدويا

### التثبيت والتشغيل (3 دقائق):

1. ثبت Node.js من nodejs.org
2. افتح Terminal / CMD في مجلد المشروع
3. شغل:
   npm install
   npm start

4. افتح المتصفح على:
   http://localhost:3000

### ماذا يوجد؟

- backend: server.js + data.json (قاعدة بياناتك)
- public/index.html: لوحة التحكم الكاملة

### المميزات:
- إضافة مطعم جديد
- تمديد اشتراك يدويا (عندما يدفع كاش)
- إيقاف مطعم لم يدفع
- ترقية الباقة
- حساب MRR تلقائي
- تنبيه الاشتراكات التي ستنتهي هذا الأسبوع
- بحث وفلترة
- حفظ دائم في data.json

### الأمان:
- لا يوجد اتصال خارجي
- لا Stripe
- لا دفع تلقائي
- يعمل على جهازك فقط أو سيرفرك الخاص

### النسخ الاحتياطي:
انسخ ملف data.json كل أسبوع واحتفظ به في مكان آمن.
